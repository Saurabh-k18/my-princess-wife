# Happy National Princess Day, Bayko! 👑

A mobile-first interactive storybook website made with love for **Darshika ("Bayko")**, signed by **Saurabh**.

## Folder Structure
- `index.html` — Main storybook layout, interactive modals, and certificate structure.
- `style.css` — Pastel parchment textures, metallic gold foil animations, and scrapbook washi tape styling.
- `script.js` — Interactive love-letter modal logic, swipeable/tappable card deck, redeemable vouchers, and royal sparkle confetti effects.

## How to Open
Simply double-click `index.html` in any web browser (Chrome, Safari, Edge, or mobile browser).
